# 人工智能课程资料（AI Course）

本仓库用于发布《人工智能》课程课件，供课前预习、课堂学习和课后复习使用。课程共 **8 次课**，从基础概念与主要方法出发，逐步介绍人工智能的应用及伦理问题。

- **授课教师**：修晔良
- **开课单位**：赣南师范大学数学与计算机科学学院
- **课程仓库**：<https://github.com/dadaqingjian/AI-Course>

## 课程介绍

课程从人工智能的定义、发展历程与研究学派讲起，介绍知识表示、搜索与博弈、智能优化、机器学习和深度学习，进而讨论主要应用领域及伦理问题。

课程结合日常生活与专业场景中的案例，帮助学习者理解不同方法解决什么问题、需要哪些信息，以及如何评价结果与认识其能力边界。

## 学习目标

通过本课程，希望同学们能够：

- 解释人工智能的基本概念，了解主要发展阶段与研究学派。
- 理解知识表示、搜索、智能优化与数据学习等方法的基本思路。
- 结合简单案例，说明算法的输入、处理过程、输出及评价方式。
- 联系本专业场景，分析人工智能可以承担的任务与需要人工核查的环节。
- 认识隐私、算法偏见、虚假信息等风险，形成负责任使用人工智能的意识。

## 课程考核

课程成绩采用百分制，由**平时成绩 40%** 和**期末考试 60%** 组成。

| 考核项目 | 占总评比例 | 评价方式 |
| --- | --- | --- |
| 课堂表现 | 20% | 根据考勤、课堂讨论等情况评分 |
| 线上作业 | 20% | 根据线上作业完成情况评分 |
| 期末考试 | 60% | 闭卷考试 |

**总评成绩 = 课堂表现 × 20% + 线上作业 × 20% + 期末考试 × 60%。**

具体考核要求以任课教师的课堂说明和教学平台通知为准。

## 资料使用与学习建议

1. 点击上表中的 PDF 链接阅读相应课件；如在线预览不便，可下载后使用本地 PDF 阅读器打开。
2. 按课程顺序学习，记录不理解的概念、算法步骤和案例问题。
3. 学习搜索、博弈与优化算法时，尝试手算简单示例，并说明每一步选择的依据。
4. 按课堂要求完成线上作业，结合课件与课堂讨论进行复习。
5. 尝试选择本专业的一个场景，说明要解决的任务、需要的信息，以及检查结果的方法。
